# Mensajero WebRTC en dos nodos Docker

Laboratorio de Sistemas Distribuidos, Universidad Tecnológica de Pereira.
Autor: Santiago Guevara.

Mensajero web en el que dos usuarios intercambian texto, audio, video y archivos y hacen videollamadas con WebRTC. El sistema corre en dos nodos (contenedores Docker) conectados por una red virtual.
